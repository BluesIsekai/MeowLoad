# 🐱 MeowLoad

> **A purr-fect video downloader with a cat-titude!**

MeowLoad is a sleek, modern desktop application built with Electron and React that makes downloading videos as smooth as a cat's purr. Powered by yt-dlp under the hood, it delivers a beautiful dark-themed interface that's both powerful and easy on the eyes.

## ✨ Features

- 🎨 **Gorgeous Dark Theme** - Easy on the eyes, purr-fect for night owls
- 📹 **Multiple Format Support** - MP4, MP3, WebM, and MKV
- 🎯 **Quality Selection** - From 360p to Best Quality
- 📊 **Real-time Progress** - Watch your downloads with animated progress bars
- 📜 **Download History** - Keep track of all your downloads
- ⚡ **Lightning Fast** - Built on yt-dlp for reliable downloads
- 🖥️ **Cross-platform** - Works on Windows, macOS, and Linux

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- FFmpeg

### Installation

```bash
# Clone the repository
git clone https://github.com/BluesIsekai/MeowLoad.git

# Navigate to the project directory
cd MeowLoad

# Install dependencies
npm install

# Start development mode
npm run ele:dev
```

## 🛠️ Available Scripts

```bash
npm run dev              # Start Vite dev server only
npm run electron:dev     # Start Electron app in development mode
npm run build            # Build for production (web)
npm run build:electron   # Build Electron app for production
npm run lint             # Run ESLint
```

## 🎯 How to Use

1. **Paste URL** - Copy any video URL and paste it into MeowLoad
2. **Choose Format** - Select your preferred format (MP4, MP3, WebM, MKV)
3. **Select Quality** - Pick the quality that suits your needs
4. **Download** - Click the download button and watch the magic happen!
5. **Enjoy** - Your video will be saved to your downloads folder
